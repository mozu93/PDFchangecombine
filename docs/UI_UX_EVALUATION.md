# UI/UXユーザーフレンドリー評価レポート

対象: PDF変換・結合ツール v1.21.2（`src/gui/` 一式）
評価日: 2026-07-07
評価方法: GUIソースコード（unified_window.py / draggable_list.py / help_dialog.py / preview_dialog.py / theme.py / update_banner.py）および config.py の静的レビュー

---

## 総合評価: ★★★☆☆（3.5 / 5）— 基礎は良好、繰り返し利用時の摩擦が課題

業務ツールとして必要な配慮（D&D対応、空状態ガイド、実行前確認、進捗表示、完了後のフォルダ自動オープン）は一通り実装されており、初見ユーザーが迷わず1回の処理を完了できる水準にあります。一方で、**「同じ操作を毎日繰り返すユーザー」の視点では改善余地が大きい**です。処理後のリスト強制クリア、設定の非永続化、モーダルダイアログの多さ、失敗時の情報不足が主な摩擦点です。

---

## 良い点（現状維持すべき設計）

| 項目 | 内容 |
|---|---|
| タブ別カラーコーディング | 変換=青 / 資料NO=緑 / 結合=オレンジ / ページ番号=紫。実行ボタン・スイッチ・出力先ボタンまで一貫しており、今どの機能にいるか一目で分かる |
| 空状態ガイド | ファイル未追加時に対応形式・操作方法をリスト内に表示。初見ユーザーへの導線が明確 |

| 番号方式のライブプレビュー | 「→ 資料1, 資料2, 資料3...」が設定変更に即時追従。結果の予測が容易 |

## 課題と改善提案

### 【優先度: 高】

#### 1. 処理完了後にファイルリストが強制クリアされる
- **箇所**: `_on_conversion_complete`（`_clear_all_conversion(force=True)`）、`_on_combination_complete`、`_on_document_number_complete`
- **問題**: 成功・失敗を問わずリストが全消去される。「オプションを1つ変え忘れて再実行したい」「失敗した3件だけやり直したい」場合に、全ファイルを再度追加し直す必要がある。繰り返し利用時の最大の摩擦点。
- **提案**:
  - リストは自動クリアせず、各行に成功✓ / 失敗✗ のステータス表示を追加する
  - 失敗ファイルがある場合は「失敗したファイルのみ再実行」ボタンを表示する
  - 少なくとも「完了後にリストをクリアする」をオプション化する

#### 2. 失敗時の詳細情報が提示されない（変換タブ）
- **箇所**: `_on_conversion_complete` — 「成功: X件 / 失敗: Y件」の件数のみ
- **問題**: どのファイルがなぜ失敗したのか分からない。ユーザーは原因を推測してすべてやり直すしかない。
- **提案**: 失敗ファイル名と理由（`result.error_message`）を一覧表示するダイアログ、またはリスト行への理由ツールチップ表示。

#### 3. 無効化された実行ボタンが「押せそうに見える」
- **箇所**: 各実行ボタン（`text_color_disabled="white"` かつ `fg_color` がタブ色のまま）
- **問題**: CTkButtonは無効時も `fg_color` を変えないため、disabled状態でも有効時とほぼ同じ見た目になる。ユーザーは押しても反応がなく「壊れている」と誤解しうる。
- **提案**: 無効時はグレー系の色に切り替える（状態変更時に `fg_color` を明示的に変更するか、無効時のみ `text_color_disabled` をグレーにする）。あわせて「なぜ押せないか」（例: 「PDFを2つ以上追加してください」）をステータスラベルに常時表示する。

#### 4. 数値入力の未検証によるクラッシュ経路
- **箇所**: `_start_combination` の `int(self.start_page_var.get())` / `int(self.start_number_var.get())`（try/except なし）
- **問題**: 開始ページ欄に空文字や非数値を入れて実行すると未捕捉の `ValueError` が発生する（ページ番号タブには同処理の try/except があり、実装が不揃い）。
- **提案**: ページ番号タブと同様の入力チェックを追加。さらに Entry の `validatecommand` で数字以外の入力自体を弾くのが望ましい。

#### 5. 設定が保存されない
- **問題**: 出力先フォルダ、フォント、フォントサイズ、各スイッチ（左綴じ対応・全ページ挿入など）が起動のたびにリセットされる。毎日同じ設定で使う業務ユーザーには毎回の再設定が負担。
- **提案**: 最終使用設定を `%APPDATA%/PDF変換・結合ツール/settings.json` に保存し、起動時に復元する。「デフォルトに戻す」も用意する。

### 【優先度: 中】

#### 6. モーダルダイアログが多い（1回の処理で最大3回の割り込み）
- **問題**: 実行確認 → 完了ダイアログ → エクスプローラー自動起動、が毎回発生する。特に変換タブでは `open_folder_callback()` が `showinfo` の**前**に呼ばれるため、エクスプローラーが開いた直後にダイアログが被さる（`_on_conversion_complete`）。
- **提案**:
  - 完了通知はモーダルではなくウィンドウ内バナー（既存の `UpdateBanner` と同様の帯）＋「📂 フォルダを開く」ボタンにする
  - フォルダ自動オープンはオプション化（デフォルトオン可）
  - 確認ダイアログに「今後表示しない」チェックを追加

#### 7. タブ間ワークフローの断絶
- **問題**: 実運用の典型フローは「変換 → 資料NO挿入 → 結合」だが、各タブのリストは独立しており、変換完了時にリストはクリアされるため、生成されたPDFを次工程で手動追加し直す必要がある。
- **提案**: 完了ダイアログ／バナーに「結果を資料NO挿入タブへ送る」「結果を結合タブへ送る」ボタンを追加する。

#### 8. キーボード操作にほぼ非対応
- **箇所**: `draggable_list.py` はマウスイベントのみバインド
- **問題**: Deleteキーでの削除、Ctrl+Aの全選択、矢印キーでの選択移動、Alt+↑↓での並び替え、Enterでの実行ができない。大量ファイルの整理はマウス操作のみになり効率が悪く、アクセシビリティ面でも弱い。
- **提案**: 最低限 Delete（選択削除）・Ctrl+A（全選択）・Esc（選択解除）を追加。

#### 9. 処理のキャンセルができない
- **問題**: 変換はファイルごとに0.5秒の待機を挟む逐次処理で、大量ファイル時は長時間かかるが、中断手段がない（ウィンドウを閉じるしかない）。
- **提案**: 処理中は実行ボタンを「⏹ キャンセル」に切り替え、ファイル境界で中断できるようにする（スレッドにキャンセルフラグを渡す）。

#### 10. ダークモード時に配色が破綻する
- **箇所**: `config.py` の `UI_THEME = "System"` と、`theme.py` のライト前提の固定HEX色
- **問題**: OSがダークモードだと外枠は暗色（`("gray95","gray10")`）になる一方、ツールバー等は `#F7FAFC` 固定で残り、明暗が混在する。ダークテキスト（#2D3748）が暗背景に載る箇所も出うる。
- **提案**: 全面対応が難しければ `UI_THEME = "Light"` に固定するのが最小コストで確実。対応する場合は theme.py の定数をすべて (light, dark) タプル化する。

### 【優先度: 低】

#### 11. 文言・表記の不統一
- 「全クリア」（変換）と「クリア」（他タブ）、「ファイル選択」と「PDF選択」が混在。ソートボタン「Ａ↓」は意味が伝わりにくい（ツールチップもない）。
- **提案**: ラベルを統一し、アイコンボタン（↑ ↓ Ａ↓）にツールチップ（ホバー説明）を追加する。

#### 12. 「参考」選択時の暗黙の設定変更
- **箇所**: `_on_prefix_changed` — 「参考」を選ぶと番号方式が勝手に「番号なし」へ、番号が「0」に変わる。
- **問題**: 意図しない設定変更に気づかないまま実行する恐れがある。プリセットとしては便利だが、変更されたことが視覚的に伝わらない。
- **提案**: 変更時にステータスラベルで「番号方式を『番号なし』に切り替えました」と通知するか、暗黙変更をやめる。

#### 13. ページ番号タブの複数ファイルドロップが黙って切り捨てられる
- **箇所**: `_add_pagenumber_files` — 複数PDFをドロップしても先頭1件のみ採用され、通知がない。
- **提案**: 「このタブは1ファイルのみ対応です。先頭のファイルを使用しました」とステータス表示する。将来的には複数ファイル対応（他タブとの一貫性）。

#### 14. 長いファイル名・パスの全体確認手段がない
- ファイル名は40文字、出力先パスは55文字で省略表示されるが、ツールチップがなく全体を確認できない。
- **提案**: ホバーでフルパスを表示するツールチップを追加。

#### 15. 補助テキストのコントラストがやや低い
- `CLR_GRAY_TEXT (#718096)` を `#F7FAFC` 背景上で使用しており、コントラスト比は約4.0:1（WCAG AAの4.5:1をわずかに下回る）。
- **提案**: `#5A6B7F` 程度まで暗くする。
